# 🎂 Age Calculator - C++

## 📌 About the Project
Age Calculator is a C++ program that calculates a person's age based on their date of birth and provides additional birthday and zodiac sign information.

## ✨ Features
- Calculates age in years.
- Calculates age in months.
- Calculates age in days.
- Calculates age in hours.
- Calculates the remaining time until the next birthday in months and days.
- Identifies the zodiac sign based on the date of birth.
- Displays the zodiac sign's characteristics, strengths, and weaknesses.

## 🛠️ Technologies Used
- C++
- Visual Studio Code

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Compile and run the C++ program.

## 🎯 Project Goal
This project is designed to practice C++ programming, date calculations, and conditional statements.
